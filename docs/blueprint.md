# **App Name**: InstaChronicle

## Core Features:

- JSON Parsing: Read and parse Instagram's exported JSON message data.
- Message Display: Display messages in a chronological order with clear separation by date.
- Date Navigation: Implement a 'Jump to Date' feature allowing users to quickly navigate to specific dates within the message history.
- Message Search: Offer a search functionality to find specific keywords or phrases within the messages.
- Local Data Persistence: Persist the loaded JSON data locally so it does not need to be re-imported upon every application loading. 

## Style Guidelines:

- Primary color: Soft Blue (#A0D2EB), evoking a sense of calm and readability.
- Background color: Light Gray (#F5F5F5), providing a clean and non-distracting backdrop.
- Accent color: Deep Blue (#3F72AF), used for interactive elements and to highlight important dates and messages.
- Font pairing: 'Inter' (sans-serif) for both headlines and body text. Note: currently only Google Fonts are supported.
- Simple and clean line icons for navigation and actions (e.g., calendar for date selection, magnifying glass for search).
- A clear, single-column layout to aid readability and message comprehension.
- Subtle transition animations when jumping to a specific date, providing smooth navigation within the message history.
